# Personal Financial Dashboard

A formula-driven Excel portfolio project that organizes synthetic transactions into a clear financial review covering cash flow, budget variance, savings rate, and net worth.

## Structure

- `index.html` — recruiter-facing STAR case study with embedded Excel preview
- `dashboard.html` — live interactive dashboard
- `css/case-study.css` — case-study styling
- `css/styles.css` — dashboard styling
- `js/app.js` — chart configuration
- `dataset/personal_finance_transactions.csv` — synthetic transaction data
- `excel/Personal_Financial_Dashboard.xlsx` — working Excel model
- `assets/banner.png` — project banner image

## Integrity note

All records are synthetic and created for demonstration. This is not real client data and the project does not provide financial, investment, tax, or legal advice.
