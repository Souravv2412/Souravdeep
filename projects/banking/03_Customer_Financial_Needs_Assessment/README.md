# Customer Financial Needs Assessment

An educational portfolio tool that demonstrates structured needs discovery, account-option discussion prompts, and documented follow-up. It uses hypothetical inputs and does not provide personalized financial advice.

## Structure

- `index.html` — recruiter-facing STAR case study with embedded Excel preview
- `dashboard.html` — live interactive needs-assessment tool
- `css/case-study.css` — case-study styling
- `css/styles.css` — assessment-tool styling
- `js/app.js` — assessment rules and Chart.js configuration
- `dataset/sample_customer_profiles.csv` — synthetic example profiles
- `dataset/product_guidance.csv` — educational category reference
- `excel/Customer_Financial_Needs_Assessment.xlsx` — offline assessment workbook
- `assets/banner.png` — project banner image

## Integrity note

All profiles are synthetic. Contribution limits and eligibility must always be verified against current official CRA information and the client's own records. This tool is not financial, investment, tax, or legal advice.
