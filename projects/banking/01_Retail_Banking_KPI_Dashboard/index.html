Project overview

What I built and why it matters

I structured a large public retail-banking campaign dataset into an interactive dashboard and Excel workbook so a reviewer can quickly compare monthly conversion, customer segments, prior outcomes, contact channels, age bands, and existing loan relationships.

STAR summary
S

Situation

The source contained 41,188 campaign contacts, making key conversion and follow-up patterns difficult to review quickly.

T

Task

Create a clear portfolio dashboard that organizes performance indicators without presenting the project as banking employment.

A

Action

Grouped performance by month, channel, segment, age band, loan relationship, and prior campaign outcome, then built Excel and web views.

R

Result

Delivered an inspectable analysis that lets recruiters explore 41,188 public records through concise KPIs, charts, tables, and source files.
