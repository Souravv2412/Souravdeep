# Retail Banking KPI Dashboard

An interactive portfolio dashboard built from the public UCI Bank Marketing dataset. It summarizes campaign volume, conversion, customer segments, contact channels, existing loan relationships, and prior campaign outcomes.

## Structure

- `index.html` — recruiter-facing STAR case study with embedded Excel preview
- `dashboard.html` — live interactive dashboard
- `css/case-study.css` — case-study styling
- `css/styles.css` — dashboard styling
- `js/app.js` — data summaries and Chart.js configuration
- `dataset/bank-additional-full.csv` — official 41,188-row source dataset
- `dataset/bank-additional-names.txt` — official data dictionary and source notes
- `excel/Retail_Banking_KPI_Dashboard.xlsx` — downloadable Excel dashboard
- `assets/banner.png` — project banner image

## Source

UCI Machine Learning Repository, Bank Marketing dataset by Moro, Rita, and Cortez. DOI: `10.24432/C5K306`. Licensed CC BY 4.0.

## Integrity note

This is a portfolio analysis of a public dataset. It is not employment experience and does not contain real customer-identifying information.
